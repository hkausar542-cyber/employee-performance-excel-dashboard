# Employee Performance Dashboard

An Excel dashboard that analyzes employee performance, attendance and task completion across departments.

## Dashboard Preview
![Employee Performance Dashboard](Screenshot%202026-10-28%20171723.png)

## Objective
Track employee performance and find which departments perform best on score, attendance and task completion.

## Tools Used
- Microsoft Excel
- Data cleaning and KPI calculations
- Charts and dashboard design

## Key Metrics
- Employees: 31
- Average performance score: 85.8
- Attendance: 93.5%
- Task completion: 91.5%
- Total hours: 5,304

## Key Insights
- Finance has the highest average score (87.4) and the highest attendance (94.8%)
- Marketing has the lowest average score (83.2)
- Sales has the lowest task completion rate (89.3%), even with strong attendance (93.9%)
